# Davilova Fit

SaaS fitness com plano gratuito e assinatura Premium, voltado a ganho de massa muscular, redução de gordura e acompanhamento de treinos.

## Produto
- Onboarding: objetivo, experiência, disponibilidade, equipamentos e restrições.
- Gratuito: biblioteca de exercícios, registro básico e treinos iniciais.
- Premium: planos adaptáveis, histórico completo, gráficos e assistência de IA.
- Não prometer resultados garantidos; evitar prescrições médicas e dietas extremas.
- Para menores de idade, priorizar orientações apropriadas à faixa etária, sem metas calóricas restritivas.

## Stack planejada
- Frontend: React + TypeScript + Tailwind CSS
- Autenticação e banco: Supabase (etapa futura)
- Pagamentos: Mercado Pago, com verificação de assinatura no backend (etapa futura)
- Hospedagem: Netlify

## Etapas
1. Landing page responsiva e dashboard demonstrativo.
2. Cadastro, login, perfil e armazenamento seguro.
3. Biblioteca de exercícios e registro de treinos.
4. Planos Premium e controle de acesso no servidor.
5. Recomendações adaptativas e IA com limites de segurança.

## Segurança
Nunca incluir tokens, chaves privadas ou credenciais no repositório. Não considerar bloqueios visuais como controle de assinatura: validar permissões no servidor.

## Status
Planejamento inicial. Ainda não há aplicação implementada ou assinatura ativa.
